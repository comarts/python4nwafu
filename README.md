# uv 虚拟环境
本项目使用 uv 管理包和虚拟环境。

## 激活虚拟环境
在项目根目录下执行：
```
source .venv/bin/activate
```
激活虚拟环境。
## 安装项目依赖
执行：
```
uv sync
```
安装项目依赖。
## 创建 jupyter kernel
执行：
```
python -m ipykernel install --user --name python4nwafu --display-name "python4nwafu(venv)"
```
执行：
```
jupyter kernelspec list
```
查看 kernel 是否创建成功。

# Emoji

Emoji（中文常称为“表情符号”），是一种用于在网络和数字沟通中表达情感、态度或语气的图形字符。它由简单的图像图标组成，代表人类的表情、物体、动作、地点等概念。虽然看起来像图片，但技术上它们是字符（Unicode 编码），不同设备上的样式可能略有不同，但本质上属于文本的一部分（因此可以被复制粘贴）。

本项目使用 Emoji 表达作者的意图：

* ✍️伴读札记及其子标题

    ✍️伴读札记及其子标题中使用 Emoji 用于区分课本原有章节，便于在 Jupyter Lab 左侧目录栏清晰标识新增的小节。

* 正文中的 Emoji

    下列 Emoji 在正文中有特定含义

含义|emoji|使用场景
:-|:-|:-
对|✅|正确答案
错|❎|错误答案
提示|💡|本段文字需要关注 
重点|📌|本段文字需要重点关注 
注意|❗|未经证实/由 LLM 生成，例如：❗以下内容使用 Qwen3.5:9B 生成
警告|⚠️|存在风险/不建议
参考文献|🔖|引用的文献
本人|🏍️|作者的观点、言论

正文中的其它 Emoji，图例、程序中的 Emoji 无专用含义。
